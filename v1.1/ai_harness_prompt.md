# Clip Saver AI 정리 지시문

아래 원문을 `note_template.md` 형식에 맞춰 Markdown 문서로 정리해줘.

## 작성 규칙

- `title`: 내용을 가장 잘 나타내는 짧은 제목
- `summary`: 2~5줄 요약
- `type`: 아래 중 하나를 선택
  - ai-log
  - architecture
  - troubleshooting
  - bug
  - feature
  - prompt
  - reference
  - idea
- `tags`: 최대 5개
  - 영어 소문자
  - kebab-case
  - 중복 금지
  - 너무 세부적인 태그보다 나중에 검색하기 좋은 태그 우선
- `content`: 원문의 핵심 내용을 보존하되 보기 좋게 정리

## 태그 예시

- ai
- gemini
- memory
- cache
- prompt
- obsidian
- python
- automation
- architecture
- troubleshooting

## 출력 형식

반드시 완성된 Markdown 문서만 출력해줘.
설명 문장이나 추가 코멘트는 붙이지 마.
